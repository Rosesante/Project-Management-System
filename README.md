# Project Management System

A web-based **Project Management System** designed to help teams organize projects, manage tasks, track progress, and improve collaboration.

## 🚀 Features

* User authentication and authorization
* Project creation and management
* Task creation, assignment, and tracking
* Project and task status management
* Dashboard for monitoring progress
* RESTful API integration
* Secure database management

## 🛠️ Technologies

* **Frontend:** React.js, CSS
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **Authentication:** JWT

## 📁 Project Structure

```text
project-management-system/
├── frontend/
├── backend/
├── database/
└── README.md
```

## ⚙️ Getting Started

### Clone the repository

```bash
git clone <repository-url>
cd project-management-system
```

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## 🎯 Purpose

The system provides a centralized platform for managing projects and tasks efficiently while giving users a clear view of project progress.
